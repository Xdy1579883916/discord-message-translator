# 🚀 Discord 消息翻译器 发布笔记

自动翻译消息列表，一键翻译输入框的消息到指定语言，全功能的双向沟通助手。

## 📜 历史版本

### v4.2.3 - 纯表情消息体验优化

*   **✨ 告别多余翻译框**
    *   纯表情消息不再发起翻译请求或显示重复的翻译框，让活跃频道的聊天内容更加清爽易读。
*   **💬 混合消息正常翻译**
    *   同时包含文字和表情的消息仍会正常翻译，并完整保留原有表情。

### v4.2.2 - 精简商店元数据

*   **📝 清晰的产品说明**
    *   精简各地区语言的标题和摘要，以自然语句说明实际功能，避免重复搜索词。
*   **🛡️ 元数据合规**
    *   从商店文案中移除独立关键词列表；扩展功能和权限均未变化。

### v4.2.1 - 界面语言控制

*   **🌐 手动选择界面语言**
    *   可从 55 个受支持的地区语言中自由选择，也可以继续自动跟随浏览器语言。
*   **⚡ 界面即时更新**
    *   切换后，弹窗和 Discord 页面内控件会立即更新语言及文字方向。
*   **🛡️ 平滑升级**
    *   原有翻译设置不受影响，并会保留旧版的中英文界面偏好。

### v4.2.0 - 全球化与多语言适配

*   **🌍 适配 55 个地区语言**
    *   扩展界面现在会跟随浏览器语言，并在缺少对应文案时可靠回退到英文。
*   **🔎 本地化商店展示**
    *   根据“实时双向翻译”的核心能力，为不同地区提供本地化的扩展名称与描述。
*   **🧭 地区用语与 RTL 支持**
    *   优化简繁中文及不同地区的表达差异，并为阿拉伯语、希伯来语和波斯语适配从右到左布局。
*   **🪶 兼容且轻量**
    *   现有阅读与写作配置保持兼容，不需要新增权限。

### v4.1.1 - 体验优化

*   **🎨 视觉更新**
    *   采用全新的 Discord 风格设计，界面更现代、清爽，优化了卡片布局与配色。
*   **🔔 配置变更提醒**
    *   新增配置修改实时提示，确保您的设置在保存后能够准确生效，防止遗忘。
*   **🔗 快速访问**
    *   弹窗底部新增“使用教程”与“问题反馈”直达链接，方便新用户快速上手。

### v4.1.0 - 功能增强

*   **📋 列表翻译支持**
    *   新增对有序列表（OL）和无序列表（UL）的翻译支持，保留完整的 HTML 列表结构，使复杂消息的阅读体验更佳。

### v4.0.0 - 双向沟通

*   **✍️ 输入框一键翻译**
    *   Discord 聊天输入框工具栏新增了一个翻译按钮（“文”字图标）。输入您的母语，点击按钮，内容将瞬间翻译为目标语言（如英文），助您轻松进行跨语言交流。

*   **🎨 设置面板**
    *   独立配置：您现在可以分别为“阅读”（接收消息）和“写作”（发送消息）设置不同的目标语言。
*   [📸 效果展示](../../issues/1)

### v3.0.0 - 体验升级

*   **⚡ 瞬时响应**
    *   新消息实时监听，“秒”翻译，告别等待。

*   **🧠 持久记忆**
    *   翻译过的消息不再重复请求，加载更迅速且节省流量。

*   **🎯 更精准的还原**
    *   修复了表情、链接和特殊符号在翻译后可能出现的错位或乱码问题。

*   **🌊 丝滑体验**
    *   大幅优化性能，即使在千人活跃大群也能流畅运行。

*   **🧹 智能管理**
    *   自动清理过期缓存，保持系统清爽。
